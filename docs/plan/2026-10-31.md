## 1단계 — 조작(오전)

1. **RC·화면 조작 버그**(UI 리뷰 확실 1·2·5·6·3·4)
   - 비행경로: 가져오기·삭제 창·⋯ 메뉴가 떠 있으면 5D 무시(`MissionListScreen` enabled5d). 저장 뒤 가져오기 창 닫힘·메시지 비움.
   - 카메라 뷰 앨범 버튼: `ic_album`, 스택 유지하고 앨범으로(비행 화면 안 닫힘). 수동 비행에도 앨범.
   - RTH 길게: 실제 1,000ms(`awaitPointerEvent`), `rememberUpdatedState`, Role·접근성 이름.
   - 판독: 고른 상자 다시 누르면 풀림·전체 보기로 돌아옴.
   - 검증: 각 항목 RC adb 재현 캡처 전·후. RTH는 0.5초 눌러 안 걸림, 1.2초 걸림(모의 기체).
2. **장갑 터치 대상**(10.4.2): 렌즈·사진/영상·줌 32dp, 앨범 32dp, ⋯·✕ 36dp 이상, 아이콘 버튼 contentDescription. 화면 배치가 깨지지 않는지 캡처.
3. **5D 조작 확대**: 계획 패널(↕ 항목, ↔ 값, 안내 다시 넣기), 앨범(↕ 미션, ●), 기체 점검(↕ 탭). 공통 `FiveDGate` 재사용, 대화상자 떠 있으면 무시, 화면 맨 위일 때만. `:core` 선택 이동 로직 단위 테스트. 실기 RC 5D 로그(`RcKey`)로 확인(adb로는 SDK 5D를 못 보냄 → 사용자 대신 로그만 남기고, 실물 누름은 사용자 확인 항목으로 증빙 README에 적음).
4. **자동 비행 중 렌즈 W/Z 허용** 설계서 06·10.4.3 문구 정리, 줌·녹화 실패 시 표시 되돌림, 렌즈 전환과 줌을 한 코루틴에서 차례로.

## 2단계 — 비행 안전·기록(오후 전반)

5. **지형 추적 시작 거절 대처**(결정대로): 실행기 `PreparingLeg`에서 시작 실패 + terrainFollow면 운용자 확인 → `relativeToStartPoint` KMZ 재생성·업로드. 미션에 `flownHeightMode` 기록(4.2 엔티티·마이그레이션 Room 버전 +1). 시뮬레이터 모드면 계획 기본 끔 + 계획 화면 "시뮬레이터: 지형 추적 끔" 표시. 시뮬레이터에서 지형 추적 미션 → 확인 창 → 이륙 기준 시작까지 증빙.
   - 원인 조사 병행: Pilot 2에서 지형 추적 웨이포인트 KMZ를 내보내 우리 KMZ와 필드 비교(가능하면), `startMission` 오류 코드·`interruptReason` OpLog.
6. **광각+망원 동시 촬영**: WPML `payloadLensIndex`를 `wide,zoom`(설정 `lenses`), 망원 배율 동작(zoom 7배) 지점 전에 한 번. 한 셔터 두 파일 → `MediaClassifier` 같은 지점 둘째 파일, 렌즈는 파일 이름(`_W`/`_Z`)으로. 판독·앨범 광각/망원 전환. 에너지·시간 예산 갱신(지점당 다운로드 2장). 시뮬레이터에서 지점마다 2파일·렌즈 맞는지 로그.
7. **설치기기 조준 사진**: 기기 있는 전주는 지점마다 둘째 `takePhoto`(짐벌만 설비 높이로, `aimHeight − equipmentDropM`, 기본 2m, 설정에 기기별). 사진 번호 대응(`shot` 안의 하위 번호 또는 같은 지점 추가 파일). 판독에 "설비" 표시. `:core` 단위 테스트(기기 있음/없음, 피치 값).
8. **사진 순서 보강**(도메인 리뷰 확실 2·6): 지점 사진은 순서대로 붙임(`next = lastShot+1`), FAILED 방문에 늦은 사진 오면 DONE, RTH 시작 때도 사진 유예 5초, `fileSuffix` 대조는 다운로드 파일 이름으로. 오늘 시뮬레이터 로그상 사진은 도착 뒤 같은 번호로 왔음 — 회귀 테스트로 고정.
9. **앱 재시작 복구(6.4)**: `recover()`에서 기체가 MISSION 모드면 먼저 `pauseMission`, 미션 이름 저장해 `stopMission`이 실제로 멈추게. 시뮬레이터에서 비행 중 앱 강제 종료 → 재실행 → 일시정지 → 재개까지 증빙.
10. **미션 상태**: 종료 시 남은 전주 있으면 `PARTIAL`, 재계획 대체는 `REPLACED`(이어하기 제외). 홈 배지·미션 표·`latestOpenMission` 맞춤, DB 마이그레이션.
11. **LDM 비행 차단**: 비행 전 점검에서 LDM 꺼짐 = 시작 불가 항목, 안내 문구. 기체 점검 IMU·나침반 null은 "--" 주의, RTH 고도는 `rthAltitudeM`과 비교.
12. **비행 화면 배터리 추정**: `energy.pathM(… aroundPoleM)` 사용(사선 전주 둘레 누락), 이동 고도 오르내림 포함, `canProceed`/`mustReturn`에도.

## 3단계 — 기능(오후 후반)

13. **충돌 경고**: `DroneGateway`에 장애물 거리(방향별) 흐름 추가(DJI `PerceptionManager` 장애물 데이터, javap로 키 확인), `:core`에 등급 판정(주의·위험 거리, 테스트), 내비 원판 부채꼴, 상단 상태 칸, `ToneNotifier` 거리별 신호음(11장). 시뮬레이터는 장애물이 없으므로 모의 기체에 장애물 주입 버튼(모의 RC 줄)으로 확인.
14. **속성 갱신**: 프로젝트 ⋯ 메뉴, SAF로 엑셀 고르기 → 전산화번호로 맞춰 갱신(새 전주·없어진 전주 수 미리보기 후 확인). 대평선으로 고/저압 기호가 판독·앨범에 나오는지 RC 캡처.

## 4단계 — 정리·보안(마무리)

15. **코드 정리**: 남은 코드(`OverlayBg`, 안 쓰는 import·매개변수, 낡은 주석), Compose 안 도메인 계산을 ViewModel/`:core`로(`perPole`, 짐벌 피치, 경로 펼치기, 홈 거리, `MissionListScreen` JSON 파싱, `SettingsHub` 문자열 분기), `getExternalFilesDir`를 `remember`로, 판독 사진 `inSampleSize`, 텍스트 측정 캐시, 홈 폴링은 화면이 보일 때만, `DjiCheck` 병렬 읽기, `initWpmz`는 처음 검사 때 IO 스레드에서, 앨범 0장 미션 제외·수동 사진 최신순, TFLite·DJI 의존성 `libs.*`로(CLAUDE.md 알려진 이슈).
