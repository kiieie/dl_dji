# 10.5 Pilot 2 대응표 (2026-11-04)

2026-11-03 현장에서 Pilot 2와 우리 앱을 같은 날 써 보았다. 그 결과 **화면 기능·배치·절차를 Pilot 2와 똑같이** 하고, 우리 앱 표지(왼쪽 위 `KEPCO 점검`, 고유색 띠)만 남기기로 했다(사용자 결정).
이 표를 기준으로 구현하고 화면을 캡처해 Pilot 2 장면과 대조한다. "미반영/다름"이 0건이 될 때까지 되풀이한다. 합의한 제외만 남긴다.

- 근거: [M] 매뉴얼 `docs/DJI_Mavic_3_Enterprise_Series_User_Manual_KR.pdf` p.51~80, [F] 11-03 녹화 장면(`docs/evidence/2026-11-03-field`). (?)는 녹화나 매뉴얼로 확인하지 못한 것이라 Pilot 2로 다시 녹화해 확인한다.
- 결정: **같게** / **추가**(우리 것, Pilot 2에 없음) / **제외**(이유를 적음)
- 상태: 미반영 → 반영 → 실기 확인
