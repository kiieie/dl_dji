# 10.5 Pilot 2 대응표 (2026-11-04)

2026-11-03 현장에서 Pilot 2와 우리 앱을 같은 날 써 보았다. 그 결과 **화면 기능·배치·절차를 Pilot 2와 똑같이** 하고, 우리 앱 표지(왼쪽 위 `KEPCO 점검`, 고유색 띠)만 남기기로 했다(사용자 결정). 2026-11-04 2차 대조(RC 캡처 ↔ Pilot 2 장면) 뒤 사용자 결정: 절차 화면은 Pilot 2처럼 **밝은 바탕**(10.1, 10.5.11), 카메라 뷰·지도는 어둡게. 상단 바 시각·미션 칸 보라 테두리·RC 배터리는 **추가(유지)**. 3차 대조(11-04 15시 RC 캡처 `r3`)에서 2차에 "반영"이라 적었지만 RC에서 틀렸던 것(배터리 띠 H·시간 상자 잘림, 비행 전 점검 HMS 칸 안 보임·범위 글 잘림·줄 선 어긋남 등)을 고쳤다. 3차 고침은 RC에 아직 설치하지 않아(조종기 배터리 0%) 상태를 "반영(3차, RC 확인 전)"으로 둔다.
이 표를 기준으로 구현하고 화면을 캡처해 Pilot 2 장면과 대조한다. "미반영/다름"이 0건이 될 때까지 되풀이한다. 합의한 제외만 남긴다.

- 근거: [F2] 11-04 Pilot 2 녹화(경로 만들기·설정·앨범·카메라 뷰), [M] 매뉴얼 `docs/DJI_Mavic_3_Enterprise_Series_User_Manual_KR.pdf` p.51~80, [F] 11-03 녹화 장면(`docs/evidence/2026-11-03-field`). (?)는 녹화나 매뉴얼로 확인하지 못한 것이라 Pilot 2로 다시 녹화해 확인한다.
- 결정: **같게** / **추가**(우리 것, Pilot 2에 없음) / **제외**(이유를 적음)
- 상태: 미반영 → 반영 → 실기 확인
- 시안: Claude Design "전주 점검 앱 화면 시안"(Pilot 2 절차 P1~P7, 시안 v2)
