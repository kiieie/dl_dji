# 4.5 전주 설비 엑셀 활용 (2026-10-30 사용자 요청)

현장에서 받는 전주 자료는 배전 설비 통계 엑셀(.xlsx)이다(예: `대평선_배전전주_좌표 (추출분).xlsx`, 1,643행, 61열, 실제 좌표라 git 제외). 지금은 CSV로 바꿔 전주번호·좌표만 쓴다. 엑셀을 그대로 가져와 아래 열을 경로·촬영·화면·결과에 쓴다. F-02(Excel 가져오기)를 1차로 앞당긴다.

## 4.5.1 쓰는 열

| 엑셀 열 | 앱 필드 | 쓰임 |
|---|---|---|
| 전산화번호 (`1365P152`) | `poleId`(고유, 기존) | 사진 파일 이름, 내보내기 키 |
| 선로명 + 선로번호 (`대평선` `13`) | `lineName`(기존), `lineNo`(새) | **화면 표시 이름 "대평선 13"**: 지도 라벨, 경로 순서, 비행 진행, 앨범·판독 목록 |
| 전주규격 (`16M`) | `lengthM`(새) | 지상 높이 = 길이 − 근입(15m 이하 길이/6, 넘으면 2.5m) → **전주별 조준 높이와 짐벌 피치**(5.6), 안전 고도 검사 |
| 설치기기 (`가공뱅크/피뢰기`) | `equipment`(새) | 지도·목록 꼬리표(변압기·개폐기·피뢰기), 판독 때 확인할 설비 |
| 고/저압, 전주형태 (`지선주`) | `guy`(새, 참·거짓) | **지선주는 기본으로 경로에서 뺀다**(계획 화면에서 다시 넣을 수 있음, 회색 점) |
| 설치년월 (`201805`) | `installedYm`(새) | 전주 정보 패널, 결과 내보내기 |
| 특기사항 | `note`(기존) | 전주 정보 패널 |
| 경도·위도 (`127.21.50.09` 도.분.초) | `lat`, `lon` | 도분초를 십진수로 바꾼다. 십진수도 받는다 |

나머지 열(접지, 점용, 제작사 등)은 쓰지 않는다. 원본 엑셀은 프로젝트 폴더에 복사해 두고 결과 내보내기에 그대로 넣는다(2차 판독 플랫폼이 원 자료를 쓸 수 있게, 미구현).

## 4.5.2 가져오기

- 파일 선택에서 `.xlsx`와 `.csv`를 함께 받는다. 엑셀은 첫 시트, 첫 행 헤더. `:core`의 `PoleCsvParser`가 행 목록(문자열 표)을 받아 헤더 동의어(4.1)로 열을 찾는다. CSV와 엑셀은 행 목록을 만드는 부분만 다르다.
- `.xlsx`는 zip 안의 `xl/sharedStrings.xml`과 첫 시트 XML을 표준 라이브러리로 읽는다(`XlsxReader`, 새 의존성 없음). 대평선 엑셀 1,643행이 문제 없이 들어온다(RC Pro 확인, `docs/evidence/2026-10-30-excel`).
- 좌표 검증(4.1 범위·뒤바뀜)은 그대로. 선로번호가 없으면 표시 이름은 전산화번호.
- 가져오기 결과에 "지선주 n개는 기본 제외" 줄을 보여 준다.

## 4.5.3 화면 반영(10장 시안)

- 계획 지도: 전주 점 옆 라벨을 선로번호(`13`)로(미구현: 오프라인 글꼴 필요). 설치기기 전주는 점 테두리를 흰색으로, 지선주는 회색 작은 점(미구현). 전주를 누르면 패널에 `대평선 13 · 1365P152 · 16M · 가공뱅크 · 2018-05 설치`.
- 비행: 진행 카드 `대평선 36 · 2/4`, 미니맵 라벨.
- 앨범·판독: 판독 목록은 선로명(작게) 위·선로번호(크게) 아래 두 줄과 상태 · 기호 · 검출 칸(11-04, 10.4.3). 앨범 썸네일은 왼쪽 아래 선로번호 크게와 방향 번호, 오른쪽 아래 기호. 판독 정렬은 경로 순서, 앨범 선로별 보기는 선로번호 자연 순서.
- **기호**(2026-10-30 승인, 12px, 모양만으로도 구분): 고압 ◆ 주황 채움, 저압 ○ 파랑 테두리, 고저압 ◇ 주황 테두리 + 가운데 파랑 점, 변압기(가공뱅크) ◎ 원 두 개, 개폐기 ─╱─, 피뢰기 ⚡ 노랑. 지선주는 기본 제외라 기호를 두지 않는다. 앨범 아래 줄에 범례.
- 결과 CSV: `전산화번호, 선로명, 선로번호, 규격, 설치기기, 판정, 탐지` 열.

## 4.5.4 저장(Room 4.2)

`POLE`에 `lineNo TEXT`, `lengthM REAL`, `equipment TEXT`, `guy INTEGER`, `installedYm TEXT`(마이그레이션 2→3), `voltage TEXT`(고/저압, 3→4)를 더한다(모두 null 허용). 3→4 전에 가져온 프로젝트는 기호를 보려면 엑셀을 다시 가져온다. 기존 프로젝트는 그대로 동작한다(표시 이름은 전산화번호, 조준 높이는 기본값 17.5m).

## 4.5.5 단계

1. `:core` 파서(도분초, 표 파서, 새 필드, 지선주 판정, 지상 높이)와 단위 테스트
2. xlsx 읽기, Room 마이그레이션, 가져오기 화면
3. 전주별 조준 높이로 짐벌 피치·관심점 높이 계산(5.6), 지선주 기본 제외
4. 화면 표시 이름·꼬리표·정보 패널, 결과 내보내기 열
5. RC Pro에서 대평선 엑셀로 가져오기 → 계획 → KMZ 확인, 증빙

## 4.5.6 선로 방향과 설비별 촬영(사용자 요청 2026-10-30)

- **선로 방향을 선로번호로**: 선로번호는 계통 구조를 담는다. `113R10L1` = 본선 113번 → 오른쪽 분기 10번째 → 왼쪽 분기 1번째. 번호가 작을수록 공급(변전소) 쪽이다. 앞 전주 = 같은 분기의 n−1(n=1이면 분기 시작 전주), 뒤 전주 = n+1. **구현함**(`core/route/LineNumbers.kt`): 4방향 사선의 선로 방향(5.6)을 번호 이웃으로 정해 분기·꺾임에서도 대각 방향이 정확하다. 계획·비행 모두 프로젝트 전체 전주로 이웃을 찾는다(영역 밖 이웃 포함). 대평선 본선 이웃 간격은 7~89m(가운데 약 46m)로, 번호 이웃이 실제로 붙어 있다. 번호 이웃이 150m보다 멀거나 없으면 지금 방식으로 둔다.
- **설치기기에 맞춘 짐벌 제어(다음 단계)**: 변압기·개폐기 전주는 설비 높이(전주 머리보다 아래)를 한 장 더 겨누는 등 촬영 각도를 설비별로 둔다. 설비별 높이 값은 현장 확인 뒤 정한다.

## 4.5.7 속성 갱신(2026-10-31)

- 비행경로 화면 프로젝트 줄의 ⋯ 메뉴 → [전주 파일로 속성 갱신]에서 엑셀·CSV를 고른다(가져오기와 같은 파서). 3→4 전에 가져온 프로젝트에 고/저압을 넣거나, 설비 자료가 바뀌었을 때 쓴다.
- 전산화번호로 기존 전주와 맞춰 선로명·선로번호·규격·설치기기·지선주·설치년월·고/저압·특기사항만 바꾼다. 파일 칸이 비어 있으면 기존 값을 둔다(지선주는 파일에 지선주가 하나라도 있을 때만 파일 값, 전주형태 열이 없는 CSV로 풀리지 않게). **좌표·미션·방문·사진·판독은 그대로**(방문은 전주 행 id를 가리키므로 행을 지우지 않는다).
- 확인 대화상자가 "바뀔 전주 n개, 파일에만 있는 새 전주 n개(추가하지 않음), 파일에 없는 전주 n개(그대로 둠)"를 보여 주고 [갱신]을 누르면 한 트랜잭션으로 바꾼다. 1차는 새 전주를 추가하지 않는다(필요하면 새 프로젝트로 가져온다). 맞추기·차이 계산은 `:core`의 `diffPoleAttributes`.
