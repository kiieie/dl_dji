사용자가 Claude Design 시안 8장을 확정했다(시안: claude.ai Artifact "전주 점검 앱 화면 시안", 768×432 = RC Pro dp). 색·크기·글꼴은 이 절이 10.2보다 우선한다. 시안 검토(독립 리뷰 25건 반영)와 Pilot 2 매뉴얼 54~56, 61, 69쪽을 기준으로 했다.

## 10.4.2 크기

- 머리글: 목록 화면 40dp(제목 가운데 14sp), 지도·카메라 화면 32dp(검정, 제목 13sp) + 배터리 띠 3dp(빨강·노랑·초록, H 표시, 남은 시간 칩). 뒤로 버튼 32dp.
- 줄: 한 줄 목록 36dp, 표 형식 40dp. **목록은 최신이 맨 위, 한 줄(불필요한 두 줄 금지), 스크롤바 4dp 항상 보임, 아래에 5D 안내**.
- 모서리 4~6dp(Pilot 2처럼 작게). 버튼 30~44dp, 스테퍼 32dp, 렌즈 버튼 32dp(장갑).

## 10.4.3 화면별 배치

| 화면 | 배치 |
|---|---|
| 홈 | 왼쪽 큰 카드(최근 미션 경로 미리보기, 전주·소티·사진, [미션 비행 시작]), 오른쪽 타일 4개(수동 비행, 비행경로, 앨범, 기체 점검) |
| 비행경로 | 왼쪽 프로젝트 목록, 오른쪽 미션 표(미션·상태·전주·소티·사진·계획일). 고른 줄에만 채운 [▶ 비행], 나머지는 회색 버튼 + ⋯ |
| 계획 | 지도 위 가운데 경로 정보 띠(길이·시간·전주·사진·소티), 왼쪽 흰 그리기 도구(활성은 파랑 테두리), 오른쪽 흰 지도 도구(전체 보기·레이어·지우기), 오른쪽 240dp 패널(고른 전주 정보, 촬영 방식, 고도·거리·피치(자동)·속도, 지형 추적, [저장] [저장하고 수행]) |
| 자동·수동 비행(카메라 뷰) | 위: 상태 칸(경고는 빨강) · 가운데 제목 · **현재 시각** · GNSS · RC · 배터리. 가운데 위 초록 줌 상자, 오른쪽 위 카메라 값(ISO·셔터·EV·SD). **오른쪽 한 열: 렌즈 W/Z → 촬영 → 앨범 → 줌 +/− → (아래) RTH 길게**(노랑 테두리). 왼쪽 위 미션 진행 카드(노랑 [Ⅱ 일시정지 · 수동 비행], RC 안내) 또는 수동 비행의 [미션 이어서 비행](착륙 시). 왼쪽 짐벌 버튼(수동), 아래 가운데 내비 원판(장애물 방향 빨강 부채꼴), 왼쪽 아래 미니맵 |
| 판독 | 왼쪽 전주 한 줄 목록(상태 · 대평선 36 · 종류·설비 기호 · 검출), 오른쪽 사진(확대·이동·두 번 탭, 검출 상자를 누르거나 칩으로 골라 그 상자로 확대), 아래 판정 [정상] [이상] [보류] |
| 앨범 | 왼쪽 미션 목록(최신순, 수동 비행 묶음 포함), 오른쪽 4열 썸네일(`대평선 36 · 1` + 기호, 탐지 빨간 점), 필터 전체/탐지만/수동 촬영, 아래 범례 |
| 기체 점검 | 왼쪽 탭(상태 점검, 비행 제어, 장애물 감지, 조종기, 영상 전송, 배터리, 짐벌·카메라, 일반), 오른쪽: 기체 종류·시리얼·펌웨어, 조종기 종류·시리얼 한 줄, **비행 모드 F/N/S(자동 비행은 N만)**, 확인 필요 항목을 맨 위 주황 + [보정 안내] |

기체 종류에 따라 바뀌는 것(렌즈 구성, 지원 기능)은 기체 점검의 기체 종류로 나눈다(M3E 1차).

## 10.4.4 RC 하드웨어(2026-10-30 로그로 확인)

| 키 | 동작 |
|---|---|

## 10.4.5 진행
