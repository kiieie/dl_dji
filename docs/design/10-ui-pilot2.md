## 10.4.6 비행 다시 보기(2026-11-04 F묶음, Pilot 2 비행 기록 리플레이)

지난 비행을 지도 위에서 시간 막대로 다시 본다. 같은 경로를 다시 나는 것은 라이브러리 ⋯ [다시 날기](10.5.8)이고, 이것은 보기만 한다.

- **기록**: 자동 비행은 소티의 `TELEMETRY_SAMPLE`(떠 있는 동안 1초, 4.2). 수동 비행(카메라 뷰)은 기체가 처음 뜰 때 `MANUAL_SESSION`을 열고 떠 있는 동안 `AppConfig.Polling.TRACK_MS`마다 `MANUAL_TRACK`에 남기며, 내리거나 화면을 떠나면 닫는다(Room 10). 운용 로그 `tele`도 그대로 남긴다.
- **들어가기**: 판독 머리글 [비행 다시 보기](미션), 라이브러리 카드 ⋯ [비행 다시 보기](궤적이 있을 때), 홈 프로필 → [비행 기록](자동 소티·수동 비행 최신순, 날짜·비행·비행 시간·거리 → 누르면 다시 보기). 미션에 궤적 있는 소티가 여럿이면 위 띠의 소티 칩으로 고른다.
- **화면**(어두운 지도, `ui/replay`): 비행 지도(`FlightMap`)를 그대로 쓴다. 기체 화살표(기수)·노란 H(수동 비행은 첫 위치)·t까지 주황 궤적·전체 궤적 흐린 주황·소티 계획 경로 녹색·전주 점, RTH 중이면 H까지 녹색 선. 사진은 파란 점(t까지 찍은 것은 진하게), 누르면 사진과 [판독](그 미션 판독 화면). 오른쪽 지도 도구는 비행 지도와 같고 지우개는 지금부터 궤적을 다시 그린다.
- **아래 띠**: ▶/⏸ · 배속 1×/4×/16×(누를 때마다) · 끌 수 있는 시간 막대 · "mm:ss / mm:ss", 그 아래 t의 ALT·SPD·배터리·짐벌·모드와 그때 시각. RC 5D ↔ 10초 찾기, ● 재생·멈춤(이 화면에서 ←는 뒤로가 아님, 화면 ‹).
- **계산**(`:core` `core/replay`): 위치·고도·속도는 앞뒤 점 선형 보간, 기수는 짧은 쪽(359° → 1°는 0°를 지남), 배터리·모드·짐벌은 앞 점. 범위 밖은 끝 점, 두 점 사이가 `AppConfig.Replay.HOLD_GAP_MS`(3초)보다 멀면 보간하지 않고 머물며 재생 시간도 그만큼으로 줄인다(다른 날 이어 난 소티도 시간 막대가 비지 않게).

## 10.4.7 핀포인트·지도 주석(2026-11-04 H묶음, Pilot 2 매뉴얼 p62~64·11-04 녹화)

현장에서 이상 위치(핀포인트)와 선로·구역 메모(선·영역)를 남기고 2차 판독 플랫폼에 넘긴다. 기기 DB에만 둔다(Room 11 `ANNOTATION`, 4.2, 외부 전송 없음, FlightHub 동기화 **제외**).

- **카메라 뷰 왼쪽 열 ◇**(`PinpointButton`): 누르면 지금 기체 위치·ALT(이륙 지점 기준)에 핀포인트. 거리계가 없어 Pilot 2도 기체 위치를 쓴다(매뉴얼 p62). 위치가 없거나 비전 포지셔닝(GNSS 등급 1 이하)이면 남기지 않고 "이용 가능한 위성이 충분하지 않습니다. 위치 레코딩 실패"를 왼쪽 열 오른쪽에 3초(`AppConfig.Annotation.NOTICE_MS`). 길게 누르면 새 핀포인트 색 5종(파랑·초록·노랑·빨강·보라)과 [모든 핀포인트 보기 >]. C1은 광각/줌이라(10.5.10) 할당하지 않는다.
- **지도 왼쪽 흰 칸**(비행·수동 비행 큰 지도, `AnnotationTools`): ◇ = 지도 가운데 십자선에 핀포인트(고도는 기체 지금 고도, 매뉴얼 p62 4b) · 선 · 영역 · ⊗ 모든 주석 지우기(확인 뒤). 그리는 도구는 검은 칸, 다시 누르면 마친다.
- **선·영역 편집**(오른쪽 패널 320dp): 이름(파랑, 누르면 바꿈) · 색 5종 원 · 길이(m)/넓이(m²) · [점 삭제](고른 꼭짓점, 없으면 마지막) [선/영역 지우기] · 노란 [확인]. 지도를 누르면 고른 점 뒤에 점을 더하고, 꼭짓점(흰 원, 고른 것 파랑)을 누르면 고른다. 구간마다 회색 길이 글자. 점이 모자라게 [확인]하면 버리고, 저장된 것을 비웠으면 지운다. 저장된 선·영역을 누르면 다시 편집.
- **핀포인트 목록**(오른쪽 패널): 색 거르기(여럿)·정렬(만든 순/최근 순/이름 순), 줄마다 ◇·이름·휴지통, 펼치면 색 5종·[이름 바꾸기]·기체까지 거리·ALT·위도·경도. 지도에서 핀포인트를 누르면 카드(같은 값, [편집] [삭제]), 기체 카드 [핀포인트]는 기체 위치에.
- **이름**: "M3E n"(`AppConfig.Annotation.NAME_PREFIX`, Pilot 2 "M3T-1 8"), n은 핀포인트·선·영역이 함께 쓰는 가장 큰 번호 + 1(`:core` `Annotations.nextName`).
- **그리기**(`ui/MapAnnotations.kt`, 모든 지도): 영역 반투명 채움+테두리, 선, 핀포인트는 색 마름모(흰 테두리). 이름은 검은 반투명 비트맵 글자(MapLibre 글꼴은 인터넷이라 안 씀, 7.4). 계획 지도는 보기·검색만(Pilot 2 경로 편집에도 없음), 다시 보기는 보기만, 미니맵은 보기만.
- **검색**: 지도 검색이 전주와 함께 주석 이름도 찾는다(합쳐 8개).
- **내보내기**: 미션 ZIP `annotations.geojson`(4.3). 미션 전주·이륙 지점 상자에서 `AppConfig.Annotation.EXPORT_MARGIN_M`(500m) 안에 점이 있는 주석만. 길이·넓이는 `:core` `Annotations`(첫 점 기준 평면 근사, 5.2).
- **미반영**: AR 투영·내비 원판 핀포인트 방향, 목록 AR 표시·보이기 거르기, 목록 내보내기 단추, POI, 홈포인트로 설정, 꼭짓점 끌기·가운데 + 손잡이.
