## 10.4.2 크기

- 머리글: 목록 화면 40dp(제목 가운데 14sp), 지도·카메라 화면 32dp(검정, 제목 13sp) + 배터리 띠 3dp(빨강·노랑·초록, H 표시, 남은 시간 칩). 뒤로 버튼 32dp.
- 줄: 한 줄 목록 36dp, 표 형식 40dp. **목록은 최신이 맨 위, 한 줄(불필요한 두 줄 금지), 스크롤바 4dp 항상 보임, 아래에 5D 안내**.
- 모서리 4~6dp(Pilot 2처럼 작게). 버튼 30~44dp, 스테퍼 32dp, 렌즈 버튼 32dp(장갑).

## 10.4.3 화면별 배치

| 화면 | 배치 |
|---|---|
| 홈 | 왼쪽 큰 카드(날 미션 = 남은 전주가 있는 가장 최근 미션, 없으면 가장 최근 미션. 경로 미리보기: 이륙 지점 H, 방문 순서 선, 전주 점과 **전주번호**(선로번호, 없으면 전산화번호 끝 4자리, 겹치면 방문 순서가 앞인 번호만, 전주 40개 넘으면 번호 생략. 10-30 사용자 추가, 시안에 없음), 전주·소티·사진, [미션 비행 시작]/[미션 이어서 비행], 끝난 미션은 [새 계획]. 판독은 앨범에서만(10-30 사용자 지정)), 오른쪽 타일 4개(수동 비행, 비행경로, 앨범, 기체 점검) |
| 비행경로 | 왼쪽 프로젝트 목록, 오른쪽 미션 표(미션·상태·전주·소티·사진·계획일). 고른 줄에만 채운 [▶ 비행], 나머지는 회색 버튼 + ⋯ |
| 계획 | 지도 위 가운데 경로 정보 띠(길이·시간·전주·사진·소티), 왼쪽 흰 그리기 도구(활성은 파랑 테두리), 오른쪽 흰 지도 도구(검색·전체 보기·레이어·지우기·과녁, 10.5.4), 오른쪽 240dp 패널(고른 전주 정보, 촬영 방식, 고도·거리·피치(자동)·속도, 지형 추적, [저장] [저장하고 수행]) |
| 자동·수동 비행(카메라 뷰) | 위: 상태 칸(경고는 빨강) · 가운데 제목 · **현재 시각** · GNSS · RC 신호 · 기체 배터리 · **RC 배터리**(조종기 자체, 안드로이드 `ACTION_BATTERY_CHANGED`, 기체 배터리와 같은 그림, 30% 아래 빨강, 충전 중 ⚡, 10-31). 가운데 위 초록 줌 상자, 오른쪽 위 카메라 값(ISO·셔터·EV·SD). **오른쪽 한 열: 렌즈 W/Z → 사진/영상 → 촬영 → 앨범 → 줌 +/− → (아래) RTH 길게**(노랑 테두리). 줌 +/− 사이에 지금 배율, 단계 1·2·4·7·14·28X(망원 렌즈만, 광각에서 누르면 먼저 Z로 바꿈). 영상 모드에서는 셔터가 녹화 시작/정지(녹화 중 빨간 네모, 아래 경과 mm:ss). 영상은 SD에만 남기고 앱으로 받지 않는다(사진만 다운로드·탐지). 자동 비행에서 렌즈 W/Z는 언제든(영상 보기만), 줌·영상 전환·녹화는 일시정지 중에만 쓰고, 재개하면 녹화를 멈추고 사진 모드로 돌린다(지점 사진의 렌즈·배율은 KMZ가 정함, 10-31). 카메라 명령은 누른 차례대로 하나씩 보내고, 기체가 거절하면 화면 표시를 되돌린다. 왼쪽 위 미션 진행 카드(노랑 [Ⅱ 일시정지 · 수동 비행], RC 안내) 또는 수동 비행의 [미션 이어서 비행](착륙 시). 왼쪽 짐벌 버튼(수동), 아래 가운데 내비 원판(장애물 방향 부채꼴, 아래 충돌 경고), 왼쪽 아래 미니맵 |

**충돌 경고**(2026-10-31): 기체 장애물 거리(`DroneGateway.obstacles`, M3E는 `PerceptionManager` 장애물 데이터)를 앞·오른쪽·뒤·왼쪽 90° 칸과 위로 묶어 등급을 매긴다(`core/model/Obstacles.kt`). 주의 10m 이하 주황(`Warning`), 위험 5m 이하 빨강(`Error`), 1m 더 멀어져야 등급을 내린다. 아래(땅)와 땅에 있을 때는 경고하지 않는다. 내비 원판에 기수 기준 방향별 부채꼴, 상단 상태 칸에 가장 가까운 방향 "앞 장애물 6.4m"(위험은 빨강 바탕, 주의는 주황 점), 신호음은 11장. 모의 기체는 모의 RC 줄 [장애물](없음→8m→4m→없음)로 확인한다. **센서 확인**(2026-11-04): 기체 점검 → 감지에 방향별 거리(앞·오른쪽·뒤·왼쪽·위·아래)를 땅에서도 그대로 보여, 실내에서 손·판을 대어 단위와 방향을 확인한다(11-03 현장은 땅에서 시험해 경고가 나오지 않았고, 착륙 때 "위 1.8m"가 의심스러웠음).
| 판독 | 왼쪽 전주 한 줄 목록(상태 · 대평선 36 · 종류·설비 기호 · 검출), 오른쪽 사진(확대·이동·두 번 탭, 검출 상자를 누르거나 칩으로 골라 그 상자로 확대), 아래 판정 [정상] [이상] [보류] |
| 앨범 | 왼쪽 미션 목록(최신순, 수동 비행 묶음 포함), 오른쪽 4열 썸네일(`대평선 36 · 1` + 기호, 탐지 빨간 점), 필터 전체/탐지만/수동 촬영, 아래 범례 |
| 기체 점검 | 왼쪽 탭(상태 점검, 비행 제어, 장애물 감지, 조종기, 영상 전송, 배터리, 짐벌·카메라, 일반), 오른쪽: 기체 종류·시리얼·펌웨어, 조종기 종류·시리얼 한 줄, **비행 모드 F/N/S(자동 비행은 N만)**, 확인 필요 항목을 맨 위 주황 + [보정 안내] |

기체 종류에 따라 바뀌는 것(렌즈 구성, 지원 기능)은 기체 점검의 기체 종류로 나눈다(M3E 1차).

## 10.4.4 RC 하드웨어(2026-10-30 로그로 확인)

| 키 | 동작 |
|---|---|
| `<`(안드로이드 뒤로) | 뒤로. 홈에서는 "앱을 종료할까요?" 확인, 수동 비행 중(날고 있음)과 자동 비행 중에는 무시 |
| `○`(C3, 안드로이드 BUTTON_A) | 확인 = 5D 누름. 카메라 뷰에서는 촬영. 화면이 맨 위일 때만 받는다 |
| 좌측 다이얼 | 짐벌 상하(기체가 직접 처리) |
| 우측 다이얼 | 줌(기체가 직접 처리) |
| 5D | 10.3 허용 목록과 같음. 목록 화면은 ↕ 고르기, ● 실행. 계획 패널 ↕ 항목·↔ 값(고른 항목 파랑 테두리), 앨범 ↕ 미션·● 열기, 기체 점검 ↕ 탭. 대화상자·메뉴가 떠 있으면 받지 않고 맨 위 화면만 받는다(`core/input` `fiveD()`) |

**절차 화면(11-04 E묶음, 10.5.5·10.5.8)**: 홈은 왼쪽 표지·프로필·데이터 보호, 최근 미션 카드, 타일 비행 경로·앨범, 오른쪽 기체 판과 [카메라 뷰 입력]으로 바뀌었다. 비행경로는 라이브러리(카드 2열)로, 비행 전 점검은 대화상자에서 한 화면으로, [업로드 후 시작]은 체크리스트 두 단계로, 계획 화면 가운데 띠는 왼쪽 위 경로 칩으로 바뀌었다. 위 표의 홈·비행경로·계획 줄은 그 전 배치다.

## 10.4.5 진행

토큰·글꼴 적용(`a353dd2`), 판독 확대·객체 고르기 완료. 홈·비행경로 다시 그리기 완료(10-30, 비행경로는 프로젝트 줄 길게 누르면 삭제·미션 ⋯ 메뉴(결과·삭제)·5D ↕●, 경로 미리보기·타일 4개, 연동 검증은 앱 이름 길게 누르기, RC 캡처 `docs/evidence/2026-10-30-home`). 화면별 Compose 다시 그리기와 목록 5D·스크롤바, 앨범(사진 모아 보기)·기체 점검 화면은 이어서 한다. 화면마다 RC 캡처를 시안과 나란히 증빙한다.
