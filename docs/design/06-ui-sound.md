## 10. 화면 설계 (가로 1920×1080)

**DJI Pilot 2 대응(2026-10-30 사용자 요청)**: 현장에서 Pilot 2 없이 본 앱만 쓰도록, 화면·흐름·톤을 Pilot 2(M3E 사용자 매뉴얼 51~76쪽)에 맞춘다. 기능은 전주 점검에 필요한 것만 둔다(핀포인트, POI, 매핑·경사·선형 임무, 라이브 임무 녹화는 두지 않음).

| Pilot 2 | 본 앱 |
|---|---|
| 홈: 비행경로·앨범 타일, 상태 관리(HMS) 카드, [카메라 뷰로 들어가기] | ① 홈: [비행경로](프로젝트·미션) [앨범](결과) [설정] 타일, 기체 상태 카드, [카메라 뷰로 들어가기] |
| 카메라 뷰 상단 바(상태 표시줄, 비행 상태·N/S, 배터리 바, GNSS, 신호, 배터리, ⚙) | ④ 비행 상단 바 같은 순서 |
| 렌즈 전환·셔터·재생·짐벌 모드, 내비게이션 디스플레이, 지도 뷰 | ④ 오른쪽 버튼, 아래 가운데 계기, 왼쪽 아래 지도 |

| 설정 탭(비행 제어, 감지, 조종기, 영상 전송, 배터리, 짐벌, 일반) | ⑥ 설정에 기체 설정 탭 추가(SDK 키로 읽고 씀) |

본 앱으로 못 하는 것: 펌웨어 업데이트, GEO 구역 온라인 잠금 해제·DB 갱신(LDM이 막음), DJI 계정·클라우드. 출동 전 사무실에서 Pilot 2로 맞춘다.

| 화면 | 주요 요소 |
|------|-----------|
| ① 프로젝트 목록 | 프로젝트 카드(전주 수, 점검 진행률), 새 프로젝트, 설정 |
| ② 데이터 가져오기 | 파일 선택(SAF), 인코딩 자동 판별, 헤더 자동 인식(실패 시에만 컬럼 매핑), 미리보기, 오류 목록 |
| ③ 계획(지도) | 전체 화면 지도, 전주 마커(상태별 색상, 묶지 않고 하나하나 점으로 표시, 축소하면 작은 점), 영역 그리기(사각형/다각형), 선택 전주 수, 경로와 소티 색상, 예상 거리·시간(배터리 %는 업로드 전 비행 전 점검에서, 5.5), 핵심 파라미터 4개(이동 고도, 점검 고도, 속도, 배터리 예비율)와 접힌 "고급" 패널, "비행 시작" |
| ④ 비행 | Pilot 2 카메라 뷰(매뉴얼 54~57쪽): **FPV 영상(메인)** + 얇은 상단 바(← · 시스템 상태 · 비행 상태 · GNSS · 신호 · 배터리 % · ⚙)와 그 아래 배터리 바(노란 막대 = 복귀 필요량) + 왼쪽 위 **경로 진행 알약**(55쪽: [Ⅱ 수동 비행] / [▶ 재개], 소티·전주·처리 수) + 오른쪽 렌즈·셔터·짐벌(바탕 없음) + 아래 가운데 내비게이션 디스플레이 + 왼쪽 아래 미니맵(180×112dp, 누르면 자리 바꿈). **자동 비행 중 비행에 영향을 주는 화면 버튼은 [Ⅱ 수동 비행]과 [RTH 길게]뿐**이다. 렌즈 W/Z 전환과 앨범은 자동 비행 중에도 쓸 수 있다(FPV 보기만 바뀌고 지점 사진의 렌즈·배율은 KMZ가 정함, 앨범을 열어도 비행 화면과 실행기는 뒤에 남음, 2026-10-31). [Ⅱ]는 RC 일시정지 버튼과 같다(멈춰 호버링 → 스틱 조종). 일시정지 상태에서 큰 초록 **[▶ 재개 (C1)]**과 [건너뛰기] [완료 처리], 셔터가 켜진다. **비행 중에는 촬영에만 집중한다**(2026-10-30 사용자 요청): 탐지는 뒤에서 저장만 하고 알림음·대기 없이 다음 전주로 가며, 판독(검출 보기)은 미션이 끝난 뒤 결과 화면에서 한다. |
| ①-1 미션 목록 | 프로젝트 안의 미션 카드(상태, 남은 전주, 마지막 비행 날짜, 판독 진행률), [새 계획] [이어하기] [판독] |
| ⑤ 결과·1차 판독 | 전주 목록과 지도, 사진 뷰어(탐지 박스 표시), 필터(검출·미판독·판정별), 판정 패널, 원본 일괄 다운로드, 내보내기 |
| ⑥ 설정 | 오프라인 지도 관리, 모델 관리, 비행 파라미터 기본값과 프리셋, 에너지 모델 보정값, 오프라인 모드, LDM 상태 |

- FPV와 텔레메트리 위젯은 DJI UX SDK(샘플 저장소의 `android-sdk-v5-uxsdk`) 컴포넌트를 재사용한다. Compose에서는 `AndroidView`로 감싼다.
- 화면의 **[재개]** 버튼은 하드웨어 재개가 불가능할 때를 위한 보조 수단이며, 화면에서 가장 크고 초록색이다. 장갑을 낀 손가락으로 쉽게 누를 수 있도록 화면 하단 중앙에 두고, 일시정지 상태에서만 표시한다. 자동 비행 중에는 잘못 누를 수 있는 버튼을 두지 않는다.
- ③ 계획 화면의 전주 개별 포함/제외(F-06): 영역 안 전주를 누르면 전주 카드에 [제외] 또는 [포함] 버튼이 나온다. 제외한 전주는 지도에 회색으로 표시하고 경로 계산에서 뺀다. 핵심 파라미터 4개는 장갑을 낀 손가락으로 누를 수 있게 [−][+] 버튼(48dp)으로 바꾸고, 6.3 범위를 벗어나면 오류 문구를 보여 주고 경로 계산을 막는다.
- ③ 새 계획을 열면 이륙 지점을 지금 위치(위성 6개 이상일 때 기체 GPS → 조종기 GPS → 없으면 지도에서 선택, 2026-10-30 사용자 지정)로 미리 두고 지도를 그 둘레 약 500m로 옮긴다. 위치를 못 받으면 비워 두고 사용자가 찍는다(2026-10-30 사용자 요청). 영역 꼭짓점을 누른 순서 때문에 변이 꼬이면 중심 둘레 각도 순으로 다시 놓는다.
- 기체 연동(`DjiDroneGateway`) 전에는 ④ 비행 화면이 `FakeDroneGateway`로 실행된다. 이때 상태바에 "모의 기체"를 표시하고, FPV 자리는 검은 화면(안내 문구)으로 두며, 미니맵에 지도(계획 화면과 같은 위성·MBTiles 배경 위에 소티 경로, 상태별 전주 색, 이륙 지점, 기체)를 그린다. 미니맵은 손으로 움직이지 않고, 누르면 큰 화면과 자리를 바꾸며 큰 지도는 이동·확대할 수 있다. RC 하드웨어 버튼 대신 왼쪽 아래에 모의 조작([RC 일시정지] [RC 재개] [배터리 −30%])을 둔다. 실제 RC Pro 버튼도 같은 동작에 매핑한다: 일시정지 버튼 → 일시정지, RTH 버튼 → RTH(모의 기체만, 실제 기체는 펌웨어가 처리). C1·C2는 11-04부터 Pilot 2 기본값(C1 광각/줌, C2 지도/카메라)이고 재개는 화면 미션 칸 ▶(10.5.10). 모의 RC 줄은 [Ⅱ] [RTH] [−30%] [장애물]. 일시정지와 재개를 한 버튼에 두지 않는다(비상 정지 버튼을 연타하면 재개되는 위험). 영상 위 버튼과 글자는 반투명 검정 바탕(약 50%)으로 뒤가 비치게 하고, 미니맵은 버튼보다 아래 층에 그린다. 계획 화면에서 계획을 저장하면 [계획 저장]이 [비행 시작]으로 바뀐다. [다시 계획]은 4단계 뒤에 붙인다.
- ⑤ 결과 화면(1차): 고른 전주의 사진과 탐지 박스를 화면 전체에 크게 깔고, 왼쪽 전주 목록(소티·순서, 상태, 사진 수, 이상 수, 필터)과 오른쪽 판정 패널을 반투명(검정 약 55%)으로 그 위에 얹는다(2026-10-29, 사진이 작다는 사용자 의견). 사진은 한 장씩 보고 아래 가운데의 [광각]/[망원] 또는 RC Pro **C1**로 바꾸며(비행 화면의 C1은 광각/줌 보기 전환, 10.5.10), 사진을 누르면 두 패널을 숨기거나 다시 보인다. 패널을 숨겨도 판정을 알 수 있게 사진 아래 정보 상자에 판정 배지(검출 맞음 빨강, 검출 없음 초록, 재촬영 노랑, 미선택 회색)와 저장 여부를 둔다. 위쪽에 완료·건너뜀·실패·미점검·검출 개수와 [내보내기]가 있다. 화면 문구는 "이상" 대신 "검출"을 쓴다(9.2). 비행 화면의 "미션 완료"와 프로젝트 카드의 [결과]로 들어간다. 결과 지도와 원본 일괄 다운로드는 기체 연동 뒤(4단계)에 붙인다.
- RC 5D ←는 그 밖의 화면(미션 목록, 설정, 앨범, 비행 기록, 연동 검증)에서 뒤로 가기다(2026-10-29 사용자 요청). 첫 화면(앱이 닫힘), 비행 화면(안전), 판독 화면(←→가 판정), 계획 화면(↕ 미션 설정 항목, ←→ 값, 2026-10-31), 비행 다시 보기(←→가 찾기, 10.4.6)에서는 동작하지 않는다. 안드로이드 파일 선택 창은 시스템 화면이라 5D 방향이 가지 않는다. RC `<`·`○` 키와 다이얼은 10.4.4(2026-10-30).
- 내보내기(F-16): `export/<missionId>.zip`을 만든 뒤 SAF로 저장 위치를 고른다. ZIP 구성은 4.3 "내보내기 묶음"(전주·사진·객체 CSV, 경로 GeoJSON, KMZ, 전주별 사진 폴더)을 따른다. 현재 구현은 `result.csv`, `mission.json`, `images/`까지다.
- 모의 기체는 전주번호 대신 렌즈·좌표를 그린 JPEG을 돌려주고, 모의 탐지기(`FakeDetector`, 모델 버전 `fake-1`)는 사진 5장마다 1장에 조류 둥지(`bird_nest`) 박스를 낸다. 결과 화면과 검출 필터를 기체·모델 없이 확인하려는 것이다. 앱 폴더에 모델(9.1)이 있으면 TFLite 탐지기를 쓴다. 사진에는 경고 라벨(`alertLabels`) 상자를 빨간색, 그 밖의 탐지 상자를 노란색으로 그리고, 이상 개수와 [이상만] 필터는 경고 라벨만 센다.
### 10.0 사용성 원칙 (2026-10-30 사용자 요청)

- **자주 쓰는 것은 크게, 드물게 쓰는 것은 작게 또는 눌러서 펼친다.** 현장 동선은 홈 → [이어서 비행]/[카메라 뷰] → 비행 → 판독이다.
- **두 가지 비행 입구를 나눈다**(Pilot 2와 같음): 홈의 [수동 비행](Pilot 2 [카메라 뷰로 들어가기])은 미션 없는 **수동 비행** 화면(FPV, 상단 바, 내비 계기, 지도, 렌즈, 언제든 누르는 셔터(화면 버튼·RC 셔터) — 원본을 받아 최근 미션 전주가 20m 안이면 그 전주의 수동 사진으로, 아니면 `manual/<날짜>/`에 둠(6.4 RC 셔터), 짐벌, RTH, 착륙 확인. `ui/flight/ManualFlightScreen.kt`). 왼쪽 위 경로 알약(55쪽 22번)에 남은 전주가 있는 최근 미션을 보여 주고, 누르면 그 미션의 비행 화면(비행 전 점검)으로 간다. 자동 점검은 미션 카드의 [비행 시작]/[이어서 비행]으로만 들어간다(④ 비행 화면).
- 홈: 최근 미션 카드에 큰 [이어서 비행](또는 [비행 시작])과 [결과·판독]. 왼쪽 위에 소속 표시 "KEPCO"(공식 로고 파일을 받으면 이미지로 교체, 모양을 흉내 내 그리지 않음). 기체 상태는 한 줄 칩(기종·상태색·주의 이유)이고 누르면 세부(배터리, GNSS, SD, LDM, 시뮬레이터)를 연다. [비행경로] [앨범]은 중간, [설정]·[연동 검증]은 상단의 작은 버튼.
- 비행경로: 한 화면에 왼쪽 프로젝트 목록, 오른쪽 그 프로젝트의 미션(마스터-디테일). CSV 가져오기는 [+ 전주 파일] 대화상자. 프로젝트·미션 모두 [삭제](확인, 미션은 사진·KMZ 폴더도 지움). 미션 카드는 정보 한 줄 + 버튼 한 줄.
- **전체 화면**(Pilot 2와 같음): 상태바·내비바를 숨기고, 화면 가장자리를 쓸면 잠깐 나온다(`MainActivity`). RC Pro는 1920×1080px, 밀도 400이라 화면이 768×432dp뿐이므로 패널·글자를 그 크기에 맞춘다.
- 계획(2026-10-30 개편, 매뉴얼 61·68·74쪽): 지도 왼쪽 위 카드에 [‹]·프로젝트 이름·경로 정보(영역 전주, 예상 시간, 사진)·[저장], 왼쪽 세로 도구 [영역][이륙][되돌리기][지우기], 지도 오른쪽 가장자리 [검색][전체 보기][레이어(배경 지도 고르기·배경 켜기/끄기)][지우기][과녁](10.5.4, 11-04), 왼쪽 아래 [▶ 수행](저장 후 비행 전 점검), 오른쪽 전체 높이 패널(256dp, [»]로 접음)에 고른 전주(경로에서 빼기/다시 넣기)·경로 설정(촬영 방식, 고도·속도·예비율과 범위)·경로 정보(소티별). 도구 줄 옆 안내 한 줄이 지금 할 일(① 영역 → ② 이륙 → ③ 확인·수행)을 알려 준다. 경로는 영역·이륙 지점·설정·제외가 바뀔 때마다 자동으로 다시 계산한다([경로 계산] 버튼 없음). 이륙 지점은 노란 점, 고른 전주는 노란 고리. 지도 파일 추가는 설정에서만.
- 글자는 한 줄에 들어가게 줄이고(말줄임), 단어 중간에서 줄이 바뀌지 않게 한다.

### 10.1 시각 규칙 (2026-09-29)

- **Material Design 3를 엄격히 따른다.** 버튼, 칩, 카드, 대화상자, 상단 바는 Material3 컴포넌트를 쓰고, 색과 글꼴은 `MaterialTheme`의 역할(`colorScheme`, `typography`)로만 지정한다. 화면 코드에 색 값을 직접 쓰지 않는다. 예외는 사진 위 탐지 상자, 지도 레이어처럼 데이터를 그리는 색뿐이다.
- **톤앤매너는 DJI 조종 앱(DJI Pilot 2) 방식을 따른다.** 카메라 뷰·지도(비행 큰 지도·미니맵·계획 지도)는 어두운 바탕에 흰 글자, 파랑 강조색을 쓰고, 영상·지도 위의 정보는 반투명 어두운 패널에 올린다. **절차 화면(홈·라이브러리·비행 전 점검·웨이포인트 경로 체크리스트·설정·계획 오른쪽 패널·앨범)은 Pilot 2처럼 밝게** 한다: 연회색 바탕(`#F2F3F5`), 흰 카드, 검은 글자, 회색 조작 칸, 파랑 강조(2026-11-04 사용자 결정). 판독 화면은 사진을 보는 화면이라 어둡게 둔다. 초록은 정상·완료, 주황·노랑은 주의, 빨강은 위험·RTH에 쓴다. DJI 로고, 아이콘, 상표, 제품 그림은 쓰지 않는다(홈 기체 그림은 우리 선 그림). 왼쪽 위 우리 표지(KEPCO 심볼 CI)는 밝은 화면에도 그대로 둔다.
- 테마는 어두운 기본(`MyFirstAppTheme`)과 밝은 절차 화면(`LightScreen`, 화면 전체나 계획 패널처럼 한 부분을 감쌈) 두 벌이고 동적 색(Material You)은 끈다(`ui/theme/Theme.kt`). 화면 코드는 글자·바탕을 `colorScheme` 역할(onSurface, onSurfaceVariant, surfaceContainer…)로만 지정해 두 벌에서 같이 쓴다. MD3에 없는 의미 색(성공, 주의)은 확장 색으로 테마에 둔다.
- 장갑을 낀 손가락으로 누르므로 터치 영역은 MD3 최소 48dp보다 크게 둔다. 비행 중 주요 버튼은 56dp 이상이다.
- **디자인 시스템 동기화**: claude.ai 디자인 시스템 프로젝트를 `/design-sync`로 연결하면 그 토큰과 컴포넌트를 기준으로 한다. 연결 전에는 `ui/theme/`의 값이 기준이다.

- **화면 흐름**: 가져오기 → 영역 지정 → 요약과 비행 전 점검(체크 결과를 한 화면에) → 비행 → 결과 순서의 마법사 형태로 안내한다.
- **판독은 미션 뒤(F-19, 2026-10-30 변경)**: 비행 화면에는 판독 요소를 두지 않는다. 소티가 끝나면 "소티 완료" 화면은 조종사 확인(배터리 교체, 프로펠러·기체 확인 → [다음 소티 시작] / [미션 종료])만 보여 주고 검출 수도 보이지 않는다. 미션이 끝나면 [결과·판독]으로 1차 판독을 한다. 오른쪽 판정 패널에 큰 판정 버튼 3개(검출 맞음 / 검출 없음 / 재촬영), 대상 칩(조류 둥지, 이물질), 메모가 있다. AI가 놓친 대상은 칩으로 직접 추가한다. 장갑을 낀 채 판독할 수 있게 RC Pro의 **5D 버튼**을 쓴다: 위·아래 = 이전·다음 전주(목록 방향), 왼쪽·오른쪽 = 판정 이동(검출 맞음 ↔ 검출 없음 ↔ 재촬영), 가운데 누름 = 저장 후 다음. 5D 방향은 장치에서 게임패드 HAT 축으로 나오지만 앱 창에는 오지 않아(2026-10-29 확인) SDK 키 `KeyFiveDimensionPressedStatus`로 받는다. 가운데와 방향이 손가락 기울기로 겹치므로, 겹치면 둘 다 버리고 다시 누르게 한다(`core/input/FiveDGate.kt`). 비행 화면에서는 5D로 비행 명령을 하지 않는다. 앱은 이상 유무를 판정하지 않는다(9.2). 2차 판독은 내보낸 ZIP으로 다른 플랫폼에서 한다.
- **이어하기(F-20)**: 미션 카드의 [이어하기]는 남은 전주로 비행 전 점검을 연다. 마지막 비행 날짜가 오늘과 다르면 대화상자로 [이어서 비행] / [남은 전주로 새 계획] / [취소]를 묻는다. 이륙 지점이 계획과 멀면 다시 계획한다(5.4).
- **⑥ 설정(1차)**: 프로젝트 목록 상단의 [설정]으로 들어간다. 설정 값은 DataStore에 저장한다(3.4).
  - **배경 지도(7.4, 2026-10-31)**: VWorld 위성 / VWorld 일반 두 칸(2026-11-06 Bing 뺌)과 "도로·지명 라벨(VWorld 위성)" 스위치. 다음에 지도 화면을 열 때 적용(지도의 레이어 버튼에서 고르면 그 자리에서 바뀌고 여기에도 저장, 10.5.7), 계획을 저장하면 고른 지도로 미션 영역을 미리 받는다. 상태 칸의 외부 전송은 "배경 지도 타일 받기만"으로 보인다.
  - **비행 기본값(F-09)**: 이동·점검 고도, 속도, 예비율, 오프셋 거리·방위, 짐벌 피치, 렌즈(광각·망원·열화상), 대기 시간, 다운로드 방식. [−][+] 버튼(48dp)으로 바꾸고, 6.3 범위를 벗어나면 오류를 보여 주고 저장을 막는다. 새 계획(다시 계획 포함)의 초기값이 된다. 이미 저장한 미션은 계획 시점의 값을 유지한다(4.2). [기본값으로 되돌리기]가 있다.
  - **탐지 모델(F-18)**: 앱 폴더 `models/`의 모델 목록(버전, 라벨 수, 규격 검사 결과 또는 거부 이유). 사용할 모델을 고르고, 고르지 않으면 이름이 가장 뒤인 모델을 쓴다(9.1). [모델 폴더 가져오기]는 SAF로 폴더를 고른다. 세 파일(9.1)을 규격 검사한 뒤 `models/<version>/`에 복사하고, 맞지 않으면 거부한다. [삭제]가 있다.
  - **오프라인 지도**: 앱 폴더 `maps/`의 MBTiles 목록(이름, 크기), [지도 파일 추가], [삭제].
  - **상태(읽기 전용)**: LDM은 기체 연결 뒤 확인한다(PoC ④). 앱은 외부로 데이터를 보내지 않으므로 오프라인 모드 전환은 두지 않는다.
  - MVP 이후: 프리셋, 에너지 모델 보정값 편집, 계획 화면의 "고급" 패널, 알림음 음량·음성 켜기/끄기.
- 와이어프레임: 증빙 페이지와 같은 방식의 Artifact(2026-09-29)로 공유한다.

## 11. 알림음 설계

| 이벤트 | 소리 |
|--------|------|
| 전주 도착 | 짧은 비프 + "도착" |
| 촬영·분석 완료(정상) | "점검 완료" |
| 대상 검출(조류 둥지, 이물질) | 경고음 2회 + "검출" |
| 일시정지 / 재개 | "일시정지" / "재개, 다음 전주로 이동" |
| 배터리 경고 / RTH 권고 | 반복 경고음 + "배터리 부족, 복귀 권고" |
| 오류(업로드 실패 등) | 오류음 |
| 충돌 경고(10.4.3) | 짧은 삑 반복: 주의(10m 이하) 0.8초마다, 위험(5m 이하) 0.25초마다. 등급이 바뀔 때만 시작·정지 |

- 사전 녹음한 음성 파일(ogg)을 `SoundPool`로 재생한다. 오프라인 환경이라 TTS에 의존하지 않는다.
- 음성 파일을 녹음하기 전까지는 `ToneGenerator` 신호음으로 대신한다. 이벤트마다 다른 음을 쓴다.
- 음량과 음성 켜기/끄기를 설정에서 조절한다. RC Pro 스피커가 작으면 블루투스 이어셋 사용을 권장한다.
