# 증빙: 비행 화면 DJI 배치, RC 버튼 매핑, 미니맵 위성 배경 (2026-10-29)

- 기기: RC Pro Enterprise(768×432dp, density 400), 앱 `kr.co.dl_dji` 디버그, 모의 기체(×5), 기체 없음
- 참고: 공식 샘플(MSDK V5 5.18.0)의 UX SDK 기본 화면을 RC Pro에 설치해 캡처했다. 캡처는 `docs/evidence/reports/2026-10-29-dji-sample/`(git 제외)에 있다. 샘플은 scratchpad 사본을 등록 실패에도 UX 화면이 열리게 한 줄 고쳐 `com.dji.sampleV5.aircraft.shot`으로 따로 설치했다.

## 남은 확인

1. 미니맵을 눌러 큰 지도로 바꾸기(이동·확대)
2. 앱 재시작 복구 화면에 "전주 0개 · 처리 0/0"이 보인 문제(6.4 표시). 이번 복구에서는 "전주 12개 · 처리 0/12"로 정상이어서 재현 조건 확인 필요
3. 재개 뒤에도 "앱이 다시 시작되었습니다…" 안내가 남아 있음(복구 안내를 재개 때 지울지)
4. 실제 기체에서 일시정지 버튼은 펌웨어가 제동하고 어댑터가 알린다(PoC ⑥, 시뮬레이터)
