# 실제 기체 연결(DjiDroneGateway, 방식 A) 시뮬레이터 확인 (2026-10-30)

RC Pro + M3E(프로펠러 제거, 실내, 시뮬레이터). 계획 화면에서 저장한 대평선 미션 #5를 미션 목록 [이어하기] → 비행 화면으로 실행했다. 로그 태그 `DjiDrone`(`dji-drone.log`).

- 기체가 연결되어 있으면 비행 화면이 `DjiDroneGateway`를 쓴다("모의 기체" 표시 없음, 실제 배터리 값). FPV는 `CameraStreamManager` 스트림을 `SurfaceView`에 그려 실제 카메라 영상이 나온다(`1-fpv-ready.png`).
- [비행 시작] → 비행 전 점검 통과 → 소티 KMZ 업로드·시작(`sortie_*.kmz`가 미션 폴더 `kmz/`에 남음) → 이륙 → 지점 도착 → 미션 동작으로 촬영 → 사진마다 SD 목록 조회·원본 다운로드(약 8MB, 이름 `전주번호_지점_시각_WIDE.jpg`) → 탐지·저장 → 완료 동작 RTH → [착륙 확인] → 착륙 → 소티 완료 화면(`3-sortie-done.png`).
- SD 목록은 비행 중에도 미디어 모드 없이 바로 응답했다(`SD 목록(미디어 모드 없이) 10개`).

시험 중 찾아 고친 문제:
1. 기체가 `FINISHED`를 마지막 사진보다 약 0.5초 먼저 알린다 → 마지막 전주 사진을 놓침. 끝난 뒤 5초 동안 들어온 사진도 미션 사진으로 받는다.
2. 웨이포인트가 1개면 기체가 거부한다("웨이포인트 개수는 2~65,535개") → 지점이 하나면 촬영 없는 마무리 지점을 1m 북쪽에 덧붙인다(`WpmlWriter`, 테스트 추가).
3. RTH 마지막 약 2m에서 착륙 보호가 조종사 확인을 기다린다 → 비행 화면에 [착륙 확인](Pilot 2와 같음, `2-landing-confirm.png`). RC 왼쪽 스틱을 내려도 된다.

남은 것: 4방향 미션을 이 경로로 끝까지(40지점), RC 일시정지·C1 재개를 비행 화면에서, 실제 비행(프로펠러 장착) 거리에서 다운로드 시간.
