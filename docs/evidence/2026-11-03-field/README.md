## 발견한 문제

1. **RC 셔터**: `rc SHUTTER`가 들어왔지만 새 사진 알림이 없다. 앱은 "기체가 스스로 찍는다"고 가정했다(10-30 설계). 앱이 찍도록 고친다.
2. **망원 사진 없음**: 82장이 모두 `DJI_..._V.JPG`이다. 렌즈 동시 저장 설정(`captureLenses`)이 `CANNOT_START_TASK_VLOTAGE_ALARM`으로 거절되었고, KMZ `wide,zoom`으로도 1장만 생겼다.
3. **사진 방향이 잘못 붙음**: 앱은 지점마다 2장을 기다렸다. 그래서 다음 지점에 도착하고 1초 안에 온 사진을 앞 지점의 둘째 파일(설비 사진)로 붙였다.
   - 예: #20 F111 전주의 방향 순서가 2, 2, 0, 3이 되었다(방향 1이 빠짐).
   - 사진 수 표시도 "52/128"이 되었다.
4. **이웃 전주 사이에서도 50m로 오르내림**: #19 R12→R11 구간이 62m라 이동 고도 기준(60m)을 넘었다.
5. **장애물 판정 근거 없음**: 거리 값을 기록하지 않았다. 착륙 때 "위 장애물 1.8m"가 나와 방향이 의심스럽다.
6. **수동 비행 미니맵이 흰 칸**이다. 비행 화면 미니맵은 정상이었다.
7. **지형 추적 시작 거절 이유를 모름**: 오류 코드와 KMZ 검증 결과를 기록하지 않았다.
8. **같은 이름 프로젝트가 2개**: 09:53에 daepyeong을 다시 가져왔다.
