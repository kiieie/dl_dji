## 사용자 확인으로 남은 것

- 실물 5D(계획 ↕↔, 앨범 ↕●, 기체 점검 ↕, 대화상자·메뉴 동안 무시): adb로는 SDK 5D를 보낼 수 없다. 로그 태그 `RcKey`로 확인.
- 기체를 켜고 시뮬레이터 회귀: 지형 추적 거절 창 → 이륙 기준 시작, 지점마다 광각+망원(+설비 `_E`) 파일과 렌즈 이름(`OpLog media download name`), 늦은 사진, 앱 강제 종료 복구(20초 대기 → 일시정지/복귀), 장애물 거리 단위(mm 가정).
- 가져오기 창 저장 뒤 닫힘: 시스템 파일 선택 창이 adb 탭을 받지 않아 캡처하지 않음(코드: `ProjectViewModel.save` → `cancelImport`).
