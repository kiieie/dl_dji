## 시뮬레이터에서 발견해 고친 것

1. **앱을 막 다시 켰을 때 이륙 여부를 몰라 "착륙"으로 판정** → 비행 모드 UNKNOWN으로 두고 값이 오면 맞춤(a4de34b).
2. **같은 소티를 이어 날면 열린 소티가 아님**(`endedAt` 남음) → 복구 대상에서 빠짐 → 이륙 때 다시 엶(0ab76c0).
3. **기체에 옛 미션이 중단(INTERRUPTED) 상태로 남으면 새 미션 업로드가 "기기 상태 오류"** → 올리기 전에 끝냄(9b058cc, 이름 고름 수정 포함).
4. **촬영마다 파일 1개(`DJI_..._0001_V.JPG`)** — KMZ `wide,zoom`으로도 망원 파일이 따로 생기지 않았고 `fileSuffix`도 이름에 붙지 않았다. 카메라 저장 렌즈 키(`KeyCaptureCameraStreamSettings`) 설정은 `CANNOT_START_TASK_VLOTAGE_ALARM`으로 거절. 설비 조준 사진(0.9초 뒤 둘째 파일)이 망원으로 기록되던 것을 **시간 간격으로 촬영 동작을 가르도록** 고침(0ab76c0).
5. **시뮬레이터 중 장애물 경고**: 기체가 책상 위라 센서가 0.5m를 계속 보고 → 시뮬레이터에서는 경고 끔.
6. 땅에서 지형 추적 거절 시 "일시정지(공중)"로 보이던 것 → 대기로.

## 시뮬레이터로는 확인할 수 없는 것(실기 비행 때)

- **앱 강제 종료 복구**: 시뮬레이터가 앱 프로세스에 묶여 앱을 죽이면 시뮬레이터도 꺼지고 기체가 땅으로 바뀐다. 그래서 복구는 "착륙 → 소티 닫음"으로 가는데, 이는 그 상황에서는 맞다. 실제로 떠 있을 때의 복구(미션 정지 → 일시정지 → 재개)는 단위 테스트로만 확인했다.
- **광각+망원 동시 촬영**: 실기체에서 지점마다 파일이 몇 개, 어떤 이름(`_W`/`_Z`/`_T`)으로 오는지. 운용 로그 `media download name`으로 확인. 1개뿐이면 Pilot 2의 사진 저장 렌즈 설정 방법을 찾아야 한다.
- 장애물 거리 단위(mm 가정), 지형 추적 실제 동작.
