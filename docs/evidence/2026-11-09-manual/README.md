# 2026-11-09 전문가 수동 비행 분석 (연구원 선로, 전주 5기)

## 3. 측정으로 확인한 사실

1. **전주 좌표 오차 1.6~3.2m.** 직상부 사진 5장에서 전주 머리의 화면 위치로 실제 위치를 역산하면, KML 좌표가 모두 서쪽으로 1.1~2.2m 치우쳐 있다(북쪽 방향은 ±2.6m). 원인이 지도에 찍은 핀인지 기체 GPS인지는 아직 가리지 못했다.
2. **전주마다 지면 높이가 다르다.** 완금의 상대 고도가 TEST0001 13.3m, TEST0002 11.6m, TEST0005 10.4m이었다. 이륙 지점 기준 고도로는 전주 머리 높이를 ±1.5m 안으로 알 수 없다.
3. **망원 시야가 좁다.** 8.3배에서 10m 거리 시야는 1.8×1.4m이다. 좌표 오차(2~3m)만으로도 대상이 화면 밖으로 나간다. 전문가는 화면을 보며 맞췄다.
4. **줌 2~6.9배는 광각 센서를 잘라낸 사진이다.** EXIF 초점이 24mm이고 크기가 5280이다. 6.7배는 실제 해상도가 약 790×590px이다. 망원 센서는 7배부터 쓴다. 앱은 이런 사진도 `ZOOM`으로 표시한다.
5. **망원 노출.** 1/100초, ISO 230~250, f/4.4(자동). 이번에는 흔들림이 없었지만 바람이 3m/s를 넘으면 흐릴 수 있다.
6. **탐지 모델의 크기 범위.** SUS는 모델 입력 기준 약 20~110px일 때 잡힌다(원본 광각 90~425px). 망원 근접(원본 1000~2000px)은 1280 입력에서 0건이었다. 같은 사진을 320·480 입력으로 줄이면 일부 잡힌다(망원 5장 중 2~3장). COS·LA·LP는 거의 못 잡는다(COS 0.3 안팎).
7. **장애물 경고.** 전문가의 작업 거리(3~5m) 내내 위험 단계(빨강, 0.25초 간격 삑)가 이어졌다. 로그로 위험 48건, 주의 135건(약 1초 간격).

## 5. 개선 제안 (자동 비행이 전문가 크기로 찍게)

**목표 크기**(전문가 기준, 모델이 잡는 범위와도 맞음): 광각 SUS 150~400px(화면 폭 3~8%, 1~2mm/px), 망원 상세 0.2~0.5mm/px.

**지금 설정으로 계산한 값**(사선 고도 30m, 수평 10m, 머리 13.5m): 경사 거리 19.3m에서 광각 SUS 약 66px(1.3%)로, 전문가 최소 92px보다 작다. 망원 8배(7×1.14)는 약 385px로 크기는 괜찮지만 시야가 3.6×2.7m라 좌표 오차 2~3m에 약하다.

| 우선 | 제안 | 내용 |
|---|---|---|
| 1 | **직상부 정렬 단계** | 전주 위 머리 +6~8m(장애물 없는 높이)로 가서 광각 −90°로 1장 찍는다. 화면에서 전주 머리(완금 십자)를 찾아 실제 위치를 보정한다. 좌표 오차 3m여도 광각 시야(6m 높이에서 8.7×6.5m) 안에 든다. 보정한 좌표는 전주에 저장해 다음 점검에 쓴다(`pole_pose_v3b` 모델 후보) |
| 2 | **촬영 세트를 전문가 유형으로** | C 직상부(광각, 머리 위 5~6m) → D 망원 직상부(같은 자리, 8.3배) → A 사선(광각, 경사 9~12m, −20~−40°) → D 망원 사선. 사선 4방향 30m/10m는 거리가 멀다 |
| 3 | 높이 기준을 **전주 머리**로 | 이륙 지점 상대 고도 대신, 직상부 사진이나 하향 센서로 잰 머리 높이에 맞춘다(지면 ±1.5m) |
| 4 | 망원은 7배 이상만 | 2~6.9배는 광각을 잘라낸 것이라 쓰지 않는다. 계획 화면 줌 선택을 1×/7×~ 로 나눈다. P4도 고친다 |
| 5 | 근접 수평(B)은 수동 | 3~5m 수평은 전선·전주에 닿을 위험이 있어 자동에서 뺀다. 자동은 머리 위·사선(≥8m)만 한다. 수평 근접은 일시정지 → 수동으로 |
| 6 | P1~P3 수정 | 수동 사진은 **프로젝트 전체 전주** 중 가장 가까운 것으로 붙인다(미션 밖이면 미션 밖 표시). 날지 않은 계획에는 붙이지 않는다 |
| 7 | 탐지: 크기 맞추기 | 망원 근접 사진은 더 줄여서(입력 320~640) 넣거나, 전문가 사진(17장, 상자 고치기 기능)으로 재학습한다. COS·LA 학습 자료를 보강한다 |
| 8 | 경고음 | 주의 단계는 처음에 한 번만 울리게, 위험 단계는 속도 0에서 간격을 늘리는 방안을 검토한다. 기준 거리는 그대로 둔다(사용자 결정 필요) |
