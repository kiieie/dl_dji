# 2026-10-30 UI 상태머신·디자인 규칙 검토와 최적화

사용자 요청: "프로그램의 UI 상태머신을 만들고 최적화 방안 수립, 리뷰, 수행", "디자인 룰을 정리하고 각 UI 화면을 검토".
기준 문서는 `docs/design/08-ui-rules-states.md`(10.2 디자인 규칙 수치, 10.3 UI 상태머신)이다.

## 1. 검토(10.2·10.3 대조)

RC Pro 캡처로 본 화면: 홈, 기체 상태 창, 비행경로, 전주 파일 가져오기, 계획(영역·이륙·경로·저장), 자동 비행 대기, 비행 전 점검, 수동 비행, 설정(일반·비행 제어), 앨범, 삭제 확인.
코드로만 본 상태(기체가 떠야 나옴): 일시정지, 복귀, 소티 완료, 착륙 확인, 연결 끊김.

| # | 화면 | 문제 | 규칙 |
|---|---|---|---|
| D1 | 홈 | 글자 크기를 직접 지정(24/20/16/13sp), 버튼 64dp, 큰 머리글 | 10.2 글자·크기 |
| D2 | 전주 파일 가져오기 | 채운 버튼 2개([CSV 파일 선택]·[저장]), 48dp | 채운 버튼 하나, 36dp |
| D3 | 비행 전 점검 | [취소]가 56dp 원 모양 | 주 버튼만 56dp, 보조는 36dp |
| D4 | 설정 일반 | [기본값 저장]·[되돌리기]·[모델 폴더 가져오기]·[지도 파일 추가]가 48dp | 36dp |
| D5 | 계획 | 안내 줄 [완료]·[취소] 48dp, 고른 전주 [경로에서 빼기] 40dp | 36dp |
| S1 | 수동 비행 | RC 5D ←가 뒤로 가기로 동작해 비행 중 화면을 떠날 수 있음 | 10.3 뒤로 막기 |

| S3 | 결과 경로 | `?filter` 인자를 쓰는 곳이 없음(소티 판독 제거 뒤) | 쓰지 않는 상태 |

## 2. 최적화 방안

- **S1**: 5D ← 무시 화면에 `camera`를 넣는다(`MainActivity`).
- **S2**: `missions/{pid}` 경로를 없애고 `projects?pid=`(고른 프로젝트를 연 비행경로)로 바꾼다. 홈 [비행 시작], 복구, 수동 비행 경로 알약 모두 `projects?pid=X` → `flight/X/Y`로 쌓는다. `MissionListScreen`은 비행경로 오른쪽에 넣는 쓰임만 남기고 따로 쓰던 뒤로 버튼 경로를 지운다.
- **S3**: 결과 경로를 `result/{pid}/{mid}`로 줄이고 `initialFilter`를 지운다(쓰는 곳 없음).
- **D1~D5**: 10.2 수치로 맞춘다. 홈은 `fontSize`를 테마 스타일로 바꾸고, 큰 행동 버튼은 56dp, 나머지는 36dp로 한다.
- 문서: 10.3 화면 이동도를 실제 경로와 맞춘다.

## 3. 방안 리뷰(독립 에이전트)

판정: S1 보완해서 진행, S2 보완해서 진행(선행 수정 필요), S3 그대로, D 그대로. 반영한 보완:
- 비행경로가 넘겨받은 프로젝트를 고르지 못하고, 다른 화면에서 돌아오면 선택이 맨 위로 바뀌던 기존 버그 → 처음 고른 값은 넘겨받은 pid, 맨 위가 "바뀔 때만"(새로 가져옴) 다시 고름.
- 재시작 복구가 사용자가 연 화면 위에 쌓일 수 있음 → `popUpTo("home")`.
- [비행 시작] 두 번 누름으로 비행 화면(과 기체 연결)이 둘 생길 수 있음 → `flight`·`settings`·`projects`에 `launchSingleTop`.
- 5D ←를 막을 화면 나열 대신 허용 목록(`projects`, `map`, `settings`, `verify`) — 새 화면은 기본으로 막힘.
- 대화상자가 열려 있을 때 5D ←가 뒤 화면을 닫음 → `FullscreenAlertDialog`에 `BackHandler`(대화상자만 닫음).
- 계획에서 영역을 찍는 중 뒤로 가면 영역을 잃음 → 도구만 취소.

## 4. 수행·확인

2장 방안과 3장 보완을 모두 반영하고 RC Pro에서 확인했다(기체 없이).

| 화면 | 확인 | 증빙 |
|---|---|---|
| 홈 | 10.2 수치(테마 글자, 비행 시작 56dp, 타일) | 01, 07 |
| 홈 [비행 시작] → 비행 | 비행 화면 한 개만 열림 | 02 |
| 비행 → 뒤로 | 그 프로젝트를 고른 비행경로 | 03, 08 |
| 비행경로 → 뒤로 | 홈 | 04 |
| 삭제 확인 대화상자에서 뒤로 | 대화상자만 닫힘 | 05 |
| 계획 영역 그리기 중 뒤로 | 도구만 취소, 영역 유지 | 06 |

**코드 리뷰(독립 에이전트)**: 이동 경로·5D 허용 목록·대화상자 뒤로 우선순위·복구 스택은 문제없음.
- 버그 1건 수정: 맨 위 프로젝트를 지우면 "맨 위가 바뀜"으로 보고 다른 프로젝트로 선택이 넘어감 → 전에 없던 id가 맨 위일 때만(새로 가져옴) 고르게 바꿈(`ProjectScreen`의 `knownIds`).
- 정리: 쓰지 않는 `embedded` 인자, `heightIn`·`Icon` 등 import 제거.
- 프로젝트가 하나뿐이라 맨 위 삭제 경우는 기기에서 재현하지 않았다(코드로 확인).

**남은 확인(기체 필요)**: 경로 알약 [Ⅱ 수동 비행] 일시정지, 실행기 대기 중 RTH 직접 호출.
