## 5-2. 탐지 객체 조준 촬영 가능성 (같은 날 오후 실내, 기체 켜고 땅 위)
사용자 제안: 전주 근처에서 광각 1장 → 객체 탐지 → 객체마다 화면 가운데로 겨눠 망원 촬영(초점 확인 뒤). `--es bench tapzoom`·`--es bench aim`(읽기·짐벌·초점만)으로 확인했다.

| 확인 | 결과 |
|---|---|
| DJI 내장 탭 줌(`KeyTapZoomAtTarget`) | **M3E 지원 안 함**(`KeyCameraTapZoomSupported` false) → 앱이 직접 겨눈다 |
| 짐벌 좌우(상대 각도 `KeyRotateByAngle`) | **±20° 됨**(+20 → 20.0, −40 → −19.4에서 멈춤, ±60은 `GIMBAL_ROTATE_YAW_OUT_OF_RANGE`). 기체를 돌리지 않고 10~15m 앞 ±3.6~5.5m를 겨눌 수 있다 |
| 짐벌 상하 | −15° 됨. 가운데 되돌리기(`RECENTER`)는 좌우만 되돌림(상하는 그대로) |

→ 탐지 상자 가운데의 화면 위치를 각도(atan((u−cx)/f))로 바꿔 짐벌을 그만큼 돌리면 된다. 망원 시야(약 12.7°)보다 좌우 범위(±20°)가 넓다.
